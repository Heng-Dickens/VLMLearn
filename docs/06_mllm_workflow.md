# 06 · MLLM 提示与两步框审核

## 历史示例材料的含义

| 缩写 | 材料 | 能提供什么 | 常见问题 |
|---|---|---|---|
| O | 原图 | 环境、动作和关系 | 目标小，干扰多 |
| C | 目标裁剪图 | 外观细节 | 丢失上下文，不能用裁剪坐标直接回填原图 |
| B | 带框原图 | 目标范围和标注语义 | 框线可能遮挡边缘 |
| J | 标注 JSON | 类别与精确坐标 | token 增加，须绑定图像和坐标系 |

MLLM 的“纯文字提示”只表示**没有视觉参考示例**，待测图仍然输入模型。不能写成“模型没看图”。

历史上比较过 O+B、O+C、O+C+B、O+C+B+J，以及负例、不同 shot。材料越多不一定越好：先固定同一参考集合和提示定义，再逐项消融。

## 直接检测：一套稳定格式

使用 [检测模板](../prompts/detect_hanging_object_zh.md)。先明确吊具、吊索是否属于框，是否标注落地同类物体；这类语义变化会改变真值，不能单靠更长英文解决。

输出采用原图像素坐标 `[x1,y1,x2,y2]`；记录原图尺寸、模型 resize 与坐标反变换。若模型原生输出 0–1000 或归一化坐标，先按对应协议转换，再进入统一评估。

未知、不确定目标可以不输出；负例图返回空数组。解析失败和请求失败单独记录，不能悄悄当作成功的空预测。

## 已提出但尚未验证：候选审核 + 受限修框

已有检测器先产生候选。一个 MLLM 审核调用同时输出 `accept / reject / uncertain` 与可选修正框；本地代码校验动作范围。这样新增的是一个审核步骤，无需强制引入分割。

示例边界约定：

- 中心横纵移动分别 ≤ 原框宽高的 20%；
- 新框宽高分别位于原框的 80%–120%；
- 框必须有效、位于图像内；越界或超限修正不采纳，保留原框交人工确认。

这是**本次整理选定的明确约定**，不是找回的历史实现。若要求四条边分别移动 ≤20%，需采用另一套约束，不能混用。

[审核模板](../prompts/review_and_refine_zh.md) · [约束检查代码](../src/vlmlearn/boxes.py)。

评估时单独比较：原检测器、只审核、审核+修框。记录被拒框、uncertain 数量、坐标校验失败、延迟和 token/调用成本。不要让 GT 参与候选选择或实际修框。

当前没有已核验的联合流水线收益数值。SAM 可作为未来边界研究工具，但本项目现阶段交付只保留检测框。
