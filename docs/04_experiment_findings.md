# 04 · 已有实验能说明什么

**按数据集、指标和任务协议分别比较。** 下表转录已保存的报告，没有重新运行模型或复算历史指标。

## 1. 两个300张验证集

吊物：350个GT；叉车/牵引车：Chache1/2/3/4分别40/30/40/30框，Qianyinche 48框，共188框。历史概述曾称“五类叉车”，这里以实际类别表为准。

每个方法取原AP50表中完成状态（含仅元数据）的最高AP50设置；不是等shot、等提示预算的公平模型排名。全部69行见 [runs.csv](../experiments/runs.csv)。数值单位均为%。

| 方法 | 吊物 AP50 / AP50:95 | 条件与原表编号 | 叉车 AP50 / AP50:95 | 条件与原表编号 |
|---|---:|---|---:|---|
| Grounding DINO | 1.00 / 0.52 | prompt_v2，#02 | 10.59 / 8.31 | prompt_v1，#01 |
| WeDetect | 1.17 / 0.86 | 文字_v1，#29 | 35.10 / 27.56 | prompt_v4，#33 |
| PET-DINO | 19.00 / 13.22 | 1-shot，#26 | 22.54 / 15.97 | 10-shot，#29 |
| YOLOE-v8L | 55.96 / 33.76 | 10-shot，#33 | 29.00 / 18.04 | 10-shot，#36 |
| MLLM / qwen3.8-27b | 55.13 / 42.68 | 5-shot O+B+J +5负例，#11 | 75.62 / 51.37 | 10-shot O+C+B，#21 |

MLLM行均是“完成（元数据）”，缺逐图坐标。模型标签原样保留；`27b_int8`是聊天出现的叫法，尚不能逐项确认与这些标签完全对应。

## 2. YOLOE：检测数与边界质量要一起看

| 数据集 | 1-shot AP50 | 5-shot AP50 | 10-shot AP50 |
|---|---:|---:|---:|
| 吊物 val300 | 53.03 | 54.81 | 55.96 |
| 叉车 val300 | 28.14 | 27.26 | 29.00 |

吊物1→10-shot只增加2.93个百分点；叉车没有单调提升。多示例可能减少单例偏差，也可能引入外观混杂；需固定参考样本并重复抽样，不能只增加shot。

高IoU原表中，吊物YOLOE最高AP85是 **1-shot的15.56%**，而非AP50最高的10-shot。说明“能大致找到”与“边界足够好”应分开评估。

## 3. 后续框精度分析是另一套摘要

下面是各方法在对应数据集**最高AP85**，各格可来自不同设置，不能与上表同一行直接组成某次运行的指标。完整114行（包括独立diaowu_99）见 [box_precision.csv](../experiments/box_precision.csv)。

| 方法 | 吊物val300最高AP85 | 叉车val300最高AP85 |
|---|---:|---:|
| Grounding DINO | 0.08 | 7.34 |
| WeDetect | 0.99 | 25.83 |
| PET-DINO | 8.68 | 13.46 |
| YOLOE | 15.56 | 10.94 |
| MLLM | 38.15 | 44.61 |

MLLM几何四项20% AP缺失，不能由历史合格数量反推。AP85、联合20%匹配AP、固定阈值合格率是三个指标。

## 5. 目前可下的判断

- 文字难以稳定指定特殊吊物；视觉示例在YOLOE上明显有用，但定位仍是瓶颈之一。
- 吊物与叉车的方法排序不同，应按场景报告。
- PET-DINO在现有参考与阈值下较弱。若AP非零但score≥0.5时几乎没有框，需检查分数标定、输入和参考协议，不能简单解释为“完全不会检测”。
- 近期“去掉SAVPE、只训练基础图像模块更好”尚无可核验的定量表与配置；它是重要观察，暂不是证实的机制结论。
- MLLM审核+受限修框、OVD内部两步精修都属于待验证方案；当前没有已核验的收益数据。

下一步以 [A/B/C/D消融](05_protocol_and_next.md) 为主，补保存逐图预测，再决定是优先解决语义误检还是框定位。
