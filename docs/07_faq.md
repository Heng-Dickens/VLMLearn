# 07 · 反复出现的问题

| 问题 | 一句话回答 |
|---|---|
| 图文对齐是什么？ | 让匹配图文的表示更接近；不意味着自动具备像素级定位。 |
| 融合是什么？ | 模态间用交叉注意力等交换信息；不同于只对最终向量求相似度。 |
| SAVPE 的 Mask 是分割结果吗？ | 可由人工框生成全图区域 Mask；框提示不要求先跑分割模型。 |
| SAVPE 哪些参数能训练？ | cv1–cv6 的卷积等；softmax、拼接、加权和本身无参数。 |
| 512 维视觉向量就是检测框吗？ | 不是，它表示提示目标类别/外观；坐标由回归分支输出。 |
| 视觉提示能顺便加点文本吗？ | 模型支持两种路径不代表任意加权混合就有效。按版本检查接口与训练方式。 |
| YOLOE 能同时传两种提示吗？ | 本仓库核对的官方示例分别走文本/视觉路径；历史自定义向量混合是另一项实验。不要概括成所有版本永远只支持一种。 |
| 900 个参考框是人工给的吗？ | 不是，是多尺度候选经提示匹配选择后的初始定位框。 |
| 900 个 query 都是选中图像特征吗？ | 不一定；参考框和内容 query 分开，官方实现有可学习 query embedding。 |
| PET-DINO 更复杂，应该更好吗？ | 论文能力不保证迁移到当前领域，需对齐权重、提示、输入尺度和阈值。 |
| AP50 和 Precision 一样吗？ | AP 汇总排序曲线，Precision 对应一个工作点。 |
| AP50:95 为什么低？ | 框边界可能不足，也受类别/漏检影响；需看正确类别框的 IoU 分布。 |
| R50 @ IoU≥0.5 是什么？ | 先看来源：若明确 Recall@50，50 是候选数上限；有时 R50 指 ResNet-50。不能脱离表头解释。 |
| 没有分数的 MLLM 怎么评估？ | 先报固定输出的 P/R、框质量和覆盖；同分 AP需写明并列排序规则。 |
| 训练/验证集要一样多吗？ | 不必；few-shot限制训练/参考样本，不限制验证集规模。 |
| 只训练基础模块更好说明 SAVPE 没用吗？ | 不能；可能改变了任务协议或改善了领域适配，需要 A/B/C/D 消融。 |

## 与当前项目有关的检测基础

- AABB IoU = 两框交集面积 / 并集面积；坐标系统一后计算。
- DFL 学习边界距离的离散分布，期望解码为连续距离；它不是置信度。
- 解耦头分别处理分类与回归；共享前端仍可能存在特征耦合。
- PAN 负责跨尺度信息汇合；C3/C2f/C3k2 属于特征模块演进，不等于开放词汇能力来源。
- 注意力模块（如 SE、C2PSA）改变特征表达，不直接替代类别提示编码。
- 交叉熵优化预测分布与目标标签的差异；分类损失下降不等于高 IoU框质量已解决。

YOLO 版本史、量化部署和环境排障未作为主线展开。曾有梯子站人闭集项目作为工程背景，但它的数据与指标不用于本项目 OVD横向排名。
